# Lisseth Turismo - Portal web turístico de Ambato

**Estudiante:** Britany Lisseth Olivo Mendieta  
**Destino turístico asignado:** Ambato - Tungurahua  
**Proyecto:** Examen práctico de HTML5, CSS3, GitHub y GitHub Pages

## Descripción del proyecto
Lisseth Turismo es una agencia turística ficticia desarrollada para promocionar el destino Ambato, en la provincia de Tungurahua. El sitio presenta información sobre lugares turísticos, paquetes referenciales, datos de la agencia y un formulario demostrativo de contacto / reserva.

El proyecto fue elaborado aplicando estructura semántica con HTML5, estilos con CSS3, diseño responsive y organización para su publicación mediante GitHub Pages.

## Tecnologías utilizadas
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Contenido del sitio
- **Inicio:** presentación de la agencia, imagen hero, resumen del destino y atractivos destacados.
- **Destinos:** seis atractivos turísticos de Ambato con imagen, descripción, ubicación y actividad.
- **Servicios:** cuatro paquetes turísticos y servicios complementarios.
- **Nosotros:** historia, misión, visión, valores y razones para visitar Ambato.
- **Contacto:** formulario HTML5 con campos obligatorios y validación básica.
